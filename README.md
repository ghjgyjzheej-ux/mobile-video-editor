# Motion Mosaic

This is a mobile-first video editor prototype designed for Android web browsers.

Features included:
- Touch-friendly editor interface
- Effect presets with cinematic styling
- Transition presets for clip changes
- Timestamped timeline preview
- Brightness adjustment controls
- Progressive Web App support for installable mobile use

Quick start:

```bash
npm install
npm run dev
```

Then open the local Vite URL shown in the terminal.

Project structure:
- `src/App.jsx` — main editor interface
- `src/styles.css` — mobile-first styling
- `public/manifest.webmanifest` — mobile app config
- `public/sw.js` — lightweight service worker
